# PrepMate AI — Dropout Risk Detector

A standalone Python prototype for the AI component of PrepMate AI.

## Features
- Transparent rule-based early-warning score (0–100)
- Low / Medium / High risk classification
- Key risk factors in the result
- Optional Random Forest demonstration model
- Synthetic demo data; no database or API required

## Run locally

```bash
python -m venv .venv
```

Activate the environment:

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

**Windows Command Prompt**
```bat
.venv\Scripts\activate.bat
```

**macOS / Linux**
```bash
source .venv/bin/activate
```

Install dependencies and run:
```bash
python -m pip install -r requirements.txt
python dropout_risk_detector.py
```

## Important limitation
The example Random Forest is trained on synthetic labels generated by the same
demo rules. It demonstrates the ML pipeline only; it is not evidence of real
predictive accuracy. Do not use its output to make consequential decisions about
students. Real deployment requires approved data, privacy safeguards, validation,
fairness checks, educator review, and a process for students to correct records.
